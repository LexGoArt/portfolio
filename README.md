## How these are built

Every document is a single HTML file — no framework, no build step, no dependencies
beyond a webfont. Images are inlined as data URIs, so each file opens correctly on its
own, offline, forever. That is deliberate: a strategy document that stops rendering when
a CDN changes is not a document, it is a liability.

## A note on confidentiality

These are real client projects, published responsibly. Document structure and design are
intact; commercially sensitive detail is not. Contractor pricing and budget figures have
been replaced with illustrative values, and individual colleagues appear by role rather
than by name. The thinking and the craft are real — the numbers are not.
